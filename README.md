# Testino Roulette

A polished, browser-based American roulette game with play-money bankroll tracking.

## Features

- Animated 38-pocket American roulette wheel (0 and 00)
- Player name and starting bankroll setup
- Straight-up, dozen, column, red/black, odd/even, and high/low bets
- Standard roulette payouts
- Secure browser randomness via `crypto.getRandomValues` when available
- Chip selection, undo, clear bets, result history, and bankroll tracking
- Responsive desktop/mobile layout
- No backend required

## Run locally

Open `index.html` directly, or serve the directory with any static web server.

## Payouts

- Straight up: 35:1
- Dozens: 2:1
- Columns: 2:1
- Red / Black: 1:1
- Odd / Even: 1:1
- 1–18 / 19–36: 1:1

This project uses play money only.
